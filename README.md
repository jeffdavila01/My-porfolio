# Jeffrey Davila portfolio

GitHub Pages serves the built portfolio from this repository's root.

- Portfolio: https://jeffdavila01.github.io/My-porfolio/
- NEURA Motor Parts Supply: https://jeffdavila01.github.io/My-porfolio/neura/
- Layer3: https://jeffdavila01.github.io/My-porfolio/layer/

The Vue/Vite portfolio source is in `portfolio-source/`. Run `npm ci` and `npm run build` there, then copy its `dist` contents to the repository root when updating the portfolio. Preserve `neura/` and `layer/` when publishing.

NEURA uses the same browser localStorage keys as its original root version. Its data remains browser-local and is not stored by GitHub Pages.
